# YouTube Quick Hide

Расширение для Chrome / Edge / Brave, которое добавляет кнопку **✕** на миниатюры видео YouTube.
Нажмите на неё — видео исчезнет из ленты через меню "Не интересует".

![YouTube Quick Hide](icon128.png)

## Возможности

- ✕ Кнопка быстрого скрытия на каждой миниатюре
- 🎯 Автоматически выбирает "Не интересует" или "Скрыть" в меню YouTube
- 🌐 Работает на главной ленте, в поиске, плейлистах, боковой панели
- 🚀 Плавная анимация скрытия
- 🔄 Поддержка бесконечной прокрутки (новые видео обрабатываются автоматически)

## Установка

### Способ 1: Chrome Web Store (скоро)
Установка в один клик.

### Способ 2: Вручную (сейчас)

1. Скачайте [последний релиз](https://github.com/dorpyssup/YouTube-Quick-Hide/releases)
2. Распакуйте ZIP-архив в отдельную папку
3. Откройте в браузере `chrome://extensions`
4. Включите **Режим разработчика** (правый верхний угол)
5. Нажмите **Загрузить распакованное расширение**
6. Выберите папку с распакованными файлами

Готово! Зайдите на YouTube и наведите курсор на видео — увидите кнопку ✕.
